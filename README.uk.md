# 🎧 apple-music-ru-blocklist

[English](README.md) · **Українська**

Блок-лист **російської та російськомовної музики** для **Apple Music**. До нього додано скрипт, який позначає ці треки як **«Пропонувати менше»** (дизлайк) у вашому акаунті. Запустити його можна самостійно або доручити AI-агенту в браузері. Після цього Apple Music пропонує вам цю музику значно рідше: у «Для вас», радіо, Discovery Station та автовідтворенні.

В Apple Music немає кнопки «заблокувати виконавця». Дизлайк на треці — найсильніший сигнал, доступний користувачу, тож проєкт ставить його масово: до 50 найпопулярніших треків кожного виконавця зі списку.

| | |
|---|---|
| Виконавців | **3 612** (1 033 основних + 2 579 знайдених через «схожих виконавців») |
| Треків у каталозі | **98 496** |

## Що всередині

```
data/
  artists.csv        id виконавця в Apple Music, ім'я, група (core / similar), жанри
  songs.csv          id треку, назва, виконавець, альбом, ISRC, id виконавця
  catalog.json       те саме одним JSON-файлом
scripts/
  block.js           вставити в консоль на music.apple.com — дизлайкає всі треки
  block-core.js      те саме, але лише 1 033 основних виконавців (швидше)
  unblock.js         скасування: прибирає ці дизлайки
docs/
  AI-AGENT-GUIDE.md  покрокова інструкція для Claude, ChatGPT Agent, Comet та інших агентів
  METHODOLOGY.md     як зібрано список і які в нього обмеження
```

## Швидкий старт (5 хвилин, без AI)

1. Відкрийте **https://music.apple.com** у Chrome, Edge, Safari чи Firefox на комп'ютері й **увійдіть** в акаунт.
2. Відкрийте консоль розробника: **Cmd + Option + J** на Mac, **Ctrl + Shift + J** на Windows. У Safari спершу увімкніть *Параметри → Додатково → Показувати функції для веброзробників*.
3. Відкрийте [`scripts/block.js`](scripts/block.js), натисніть **Raw** і скопіюйте все (Cmd/Ctrl + A, Cmd/Ctrl + C).
4. Вставте в консоль і натисніть **Enter**. Якщо браузер попросить ввести `allow pasting`, введіть і вставте ще раз.
5. Не закривайте вкладку. Прогрес видно в консолі, і він зберігається: якщо вкладку закрито, вставте скрипт знову, і він продовжить з місця зупинки.
6. Щоб пізніше почати з нуля (наприклад, після оновлення списку), спершу виконайте в консолі `localStorage.removeItem('amru_progress_v1')`.

> ⏱ Повний прогін триває кілька годин: після кількох десятків тисяч позначок Apple **мовчки перестає їх зберігати**. Скрипт це помічає, робить паузу на 30 хвилин і пробує знову. Якщо поспішаєте, почніть з `block-core.js`.

## Через AI-агента

Усю роботу можна доручити агенту в браузері: Claude in Chrome, Claude Cowork, ChatGPT Agent, Perplexity Comet та іншим. Готовий промпт для копіювання є в **[docs/AI-AGENT-GUIDE.md](docs/AI-AGENT-GUIDE.md)**.

## Чи це безпечно?

- Скрипт працює **лише на music.apple.com** і звертається **лише до API Apple**. Ваші токени входу не залишають сторінку.
- Він змінює **одне**: ставить треку з каталогу оцінку «не подобається». Медіатеку, плейлисти й історію він не видаляє.
- Скасувати можна будь-коли через [`scripts/unblock.js`](scripts/unblock.js).
- Перегляньте код перед запуском, він короткий.

## Обмеження (чесно)

- **Список зібрано автоматично, він не ідеальний.** Основа — російські чарти й редакційні плейлисти Apple Music. Далі список розширено через «схожих виконавців», залишаючи лише тих, у кого назви треків російською (кирилиця без українських літер). Українських, казахських, киргизьких, білоруськомовних, сербських, грузинських і західних виконавців відсіяно, очевидні помилки прибрано вручну. Деякі помилки напевно залишилися. Будь ласка, [створіть issue](../../issues) або PR.
- **Російськомовних пісень українських виконавців у списку немає.** Цілих українських виконавців ми свідомо не включали. Такі пісні можна заблокувати самостійно.
- У списку є радянські записи: музика з фільмів, дитячі хори, естрада.
- Apple Music з часом змінює каталог та ідентифікатори, тому список варто періодично оновлювати.
- Ліміт Apple на кількість позначок діє на акаунт, тож повне блокування може зайняти день-два.

## Як долучитися

PR вітаються:

- помилково доданий виконавець → видаліть рядок з `data/artists.csv` і поясніть чому;
- пропущений виконавець → додайте його Apple Music ID та ім'я.

Після цього перегенеруйте скрипти командою `python3 tools/build.py`.
